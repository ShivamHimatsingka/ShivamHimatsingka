### Hi, I'm Shivam 👋

15-year-old systems & native app builder from India. I like writing lightweight, zero-dependency software that gets close to the hardware—mostly in **Swift**, **C++**, **Kotlin**, and **Python**.

### Featured Projects

| Project | What It Does | Engineering Highlights |
| :--- | :--- | :--- |
| **[SwiftDrop](https://github.com)** | Native AirDrop-style file sharing across **Mac, iPhone, Android & Windows** (LocalSend v2 compatible). | Uses Apple peer-to-peer Wi-Fi (**AWDL**, ~40 MB/s), **BLE wake-up** for locked iPhones, and TLS-encrypted disk streaming. |
| **[Meterbar](https://github.com)** | Native macOS menu bar system monitor (CPU, GPU, RAM, SMC temps, disk, network, battery). | Runs in **~12 MB RAM** and **0.3% CPU** (`0.4 MB` binary) in a single dependency-free Swift/AppKit file with CPU-bitmap popups. |
| **[FiveK](https://github.com)** | Turns a 27" 5K iMac into a native **5120×2880** wireless extended display over Wi-Fi. | Hardware HEVC (`ScreenCaptureKit` + `VideoToolbox`), **zero idle overhead** via `launchd` socket activation, and a decoupled 120 Hz cursor. |
| **[MIDI Footcontroller](https://github.com)** | Driver-free 8-button USB MIDI foot controller for guitar rigs & DAWs. | Class-compliant USB MIDI on **ATmega32U4** (Arduino Pro Micro) with hardware debounce and configurable PC/CC messages. |
| **[Graphical Calculator](https://github.com)** | Fast, Desmos-inspired interactive desktop graphing calculator. | Built with **PySide6**, **PyQtGraph**, **NumPy**, and **SymPy** featuring two-way synced variable sliders and live curve tracking. |
